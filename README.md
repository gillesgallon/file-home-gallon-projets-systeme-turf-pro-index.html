# 🏇 TURF SYSTÈME PRO — NOVA

Version reconstruite, autonome : 20 chevaux, 5 bases, groupes A à O, filtres, développement Couplé/Trio/Quarté/Quinté, export CSV.

## Télécharger pour Windows 7
**[Télécharger le logiciel (index.html)](https://raw.githubusercontent.com/gillesgallon/file-home-gallon-projets-systeme-turf-pro-index.html/main/index.html)**

Si Firefox affiche le code HTML au lieu d'enregistrer : utiliser **Ctrl+S**, choisir « Tous les fichiers » et enregistrer sous **TURF-SYSTEME-PRO.html**, puis double-cliquer sur le fichier téléchargé.

Il fonctionne localement, sans installation, dans Firefox 115 ESR. Pour créer un raccourci, clic droit sur le fichier HTML puis « Envoyer vers » > « Bureau (créer un raccourci) ».

## Utilisation
1. Cocher les chevaux de 1 à 20, désigner jusqu'à 5 bases.
2. Renseigner si besoin les groupes A à O et les conditions.
3. Régler la course et la mise indicative.
4. Cliquer sur « Développer le système », puis exporter en CSV.

La sauvegarde locale est associée au navigateur et à son contexte d'ouverture. Garder aussi une copie du fichier. Les combinaisons sont non ordonnées ; aucun pari n'est placé et aucune garantie de gain n'est impliquée.
